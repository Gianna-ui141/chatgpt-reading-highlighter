# Privacy Policy

ChatGPT Reading Highlighter is local-first.

- Highlights, notes, source URLs, and settings are stored in `chrome.storage.local`.
- No annotation or ChatGPT content is transmitted to the developer or any third party.
- The extension does not collect analytics or telemetry.
- The extension does not read cookies, authentication tokens, passwords, browsing history, or content from other websites.
- The `activeTab` permission is used only after the user clicks the extension icon, so the icon can open the panel on the current ChatGPT tab.
- Users can remove all stored data by uninstalling the extension or clearing its extension storage.

Exported Markdown or JSON files are created only when the user presses an export button and are saved using the browser's normal download flow.
